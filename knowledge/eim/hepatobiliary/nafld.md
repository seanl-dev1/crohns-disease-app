# NAFLD / MAFLD in IBD

Reference file for Claude. Technical language.

## EIM: NAFLD in IBD

- **Prevalence ~30-40%** in IBD cohorts; higher than expected given often-lower BMI. Likely driven by corticosteroids, methotrexate, chronic inflammation, altered microbiome.
- Screen with ALT/AST, ultrasound, FIB-4 score.

### Monitoring Summary (hepatobiliary)
LFTs at baseline and every 3-12 months; MRCP if unexplained ALP elevation; annual surveillance MRCP/ultrasound for PSC patients.
