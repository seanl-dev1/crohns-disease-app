# Drug-Induced Liver Injury (DILI)

Reference file for Claude. Technical language.

## EIM: Drug-Induced Hepatitis

- **Thiopurines (azathioprine, 6-MP)**: Elevated LFTs in 3-10%; nodular regenerative hyperplasia (rare); sinusoidal obstruction syndrome. Check TPMT and/or NUDT15 pre-treatment; monitor LFTs q3 months.
- **Methotrexate**: Cumulative dose-related fibrosis; rare with modern monitoring. Check LFTs monthly initially, then q3 months. Folate supplementation mandatory.
- **Anti-TNF**: Rare DILI/autoimmune hepatitis-like picture with infliximab > others. Check LFTs periodically.
- **Sulfasalazine / 5-ASA**: Hypersensitivity hepatitis (rare, early).

### Monitoring Summary (hepatobiliary)
LFTs at baseline and every 3-12 months; MRCP if unexplained ALP elevation; annual surveillance MRCP/ultrasound for PSC patients.
