# Cholelithiasis (Gallstones)

Reference file for Claude. Technical language.

## EIM: Gallstones

- **Prevalence**: **~2-3× baseline** in CD, especially ileal disease or post-ileal resection. Crude prevalence ~13-34% in ileal CD.
- **Mechanism**: Ileal bile acid malabsorption → bile acid pool depletion → cholesterol supersaturation (cholesterol stones). A second mechanism: malabsorbed bile acids in colon solubilize unconjugated bilirubin → reabsorption → pigment stones.
- **Management**: Standard indications for cholecystectomy; no prophylactic surgery.
