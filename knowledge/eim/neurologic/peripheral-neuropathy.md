# Peripheral Neuropathy

Reference file for Claude. Technical language.

## EIM: Peripheral Neuropathy

- Causes:
  - **Vitamin deficiencies**: B12 (classic post-ileal-resection), B6, folate, copper (rare).
  - **Drug-induced**: metronidazole (dose/cumulative-dose; usually reversible but can be permanent after prolonged exposure), thalidomide (historically used for CD; now rare).
  - Primary IBD-associated neuropathies (axonal and demyelinating) reported.
- Management: replete deficiencies, discontinue offending drug, neurology referral for workup.

### When to Worry
- New peripheral numbness/weakness → B12 deficiency, demyelination, drug toxicity. B12, MRI brain/cord; stop anti-TNF if demyelination.

### Specialist Referral
Neurology — peripheral neuropathy, new demyelinating symptoms.
