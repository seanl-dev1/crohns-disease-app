# Extraintestinal Manifestations of Crohn's Disease — Index

Per-topic reference files for Claude. Each file has YAML frontmatter, a grep-anchored `## EIM:` block, and preserved citations from the original monolithic `15-extraintestinal-manifestations.md`.

## Overview / Framework Notes

**Prevalence**: Up to **50% lifetime** of IBD patients develop at least one EIM. Pooled cross-sectional prevalence **24% overall / 35% in CD** (Rogler 2024, 52 studies, 352,454 patients).

**ECCO 2024 Classification**:
1. Classical EIMs — peripheral arthritis, erythema nodosum, uveitis, episcleritis, aphthous stomatitis
2. Associations — axSpA/AS, PSC, psoriasis, autoimmune thyroid
3. Complications — anemia, osteoporosis, nephrolithiasis, VTE, amyloidosis
4. Treatment-related — paradoxical psoriasis, drug-induced hepatitis, JAK-associated VTE

**Legacy framework**:
- **Reactive / gut-parallel**: Peripheral arthritis Type 1, erythema nodosum, episcleritis, aphthous ulcers, metastatic CD — activity tracks with bowel inflammation; treat the gut.
- **Independent / gut-discordant**: Peripheral arthritis Type 2, axial SpA/AS, uveitis, PSC, pyoderma gangrenosum — often run independently of luminal activity and require their own directed therapy.

> **Pearl**: If the EIM parallels the gut, treating the gut usually treats the EIM. If the EIM is independent, you likely need a biologic with dual indication (anti-TNF) or a separate therapy in co-management.

## Quick References (from source)

### "When to Worry" Quick Reference
| Scenario | Why it matters | Action |
|----------|----------------|--------|
| Painful red eye + photophobia + blurred vision | Uveitis or scleritis — vision-threatening | **Same-day ophthalmology** |
| Deep ocular pain worse at night + violaceous sclera | Scleritis | **Same-day ophthalmology** |
| Calf swelling/pain, unexplained dyspnea in flare/hospitalized | DVT/PE — 2-3× IBD risk | Duplex US, CT-PA; LMWH |
| New severe headache in flare | Cerebral venous sinus thrombosis | MRV |
| Chest pain/SOB in young IBD patient | MI risk elevated during flare | ECG, troponin |
| Painful rapidly expanding skin ulcer with violaceous border | Pyoderma gangrenosum (don't debride — pathergy) | Dermatology; systemic steroid + infliximab |
| New jaundice or pruritus, ALP elevation | PSC progression or CCA | MRCP ± ERCP, CA 19-9 |
| New peripheral numbness/weakness | B12 deficiency, demyelination, drug toxicity | B12, MRI brain/cord; stop anti-TNF if demyelination |
| Inflammatory back pain >3 months, age <45 | Axial SpA | MRI SI joints, HLA-B27, rheum |
| Lip/face swelling with buccal cobblestoning | Orofacial granulomatosis (often oral CD) | Dermatology/GI; topical steroids |
| Fragility fracture, height loss, chronic steroid use | Osteoporosis | DEXA, start bisphosphonate if T≤-2.5 |
| Unexplained anemia | IDA (common), ACD, B12 deficiency | Ferritin + TSAT + CRP, B12, folate; IV iron if active disease |
| Patient with MS wants anti-TNF | Contraindication | Use vedolizumab, ustekinumab, or JAK instead |
| Rash or new psoriasis on anti-TNF | Paradoxical psoriasis | Topical tx; switch to ustekinumab if severe |

### Annual EIM Monitoring Checklist

**At IBD diagnosis and at least annually**
- Full history: joint pain, back pain, eye symptoms, skin changes, mood (PHQ-9, GAD-7).
- Physical: joints (tenderness, swelling, enthesitis, dactylitis), skin (perianal, sacrum, stoma), oral cavity.
- Labs: CBC + diff, CMP (LFT/renal), CRP/ESR, **Ferritin + TSAT**, B12, 25-OH vitamin D, TSH, UA, ALP trend.

**Periodic / indication-based**
- DEXA baseline if risk, repeat q2-3 years (more frequent on steroids).
- Annual comprehensive eye exam (ECCO 2024).
- Annual full-body skin exam (especially thiopurines/anti-TNF).
- Annual dental exam.
- MRCP if unexplained cholestasis → annual for PSC.
- Colonoscopy: 8 years post-diagnosis for extensive colitis, q1-3 yrs; PSC-IBD annual from PSC diagnosis.
- VTE prophylaxis for all hospitalized IBD (LMWH).
- Vaccinations: flu, pneumococcal (PCV20 or PCV15→PPSV23), HPV (to 45 on immunosuppression), COVID, RSV, zoster (Shingrix — ACIP 2022 for 19+ immunocompromised). **Avoid live vaccines** on immunosuppressants.
- TB screening before anti-TNF/JAK (IGRA + CXR).
- HBV screening before immunosuppression.
- Annual Pap on immunosuppressants.
