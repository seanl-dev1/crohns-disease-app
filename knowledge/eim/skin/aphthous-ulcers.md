# Aphthous Stomatitis (Mouth Ulcers)

Reference file for Claude. Technical language.

## EIM: Aphthous Ulcers

- **Prevalence**: 10-30% of CD patients.
- Typically parallels gut activity; minor aphthae resolve within 2 weeks.
- Treat with topical steroids (triamcinolone in Orabase, dexamethasone mouthwash); address iron/B12/folate deficiency.

### Treatment Principle
Aphthous ulcers typically respond to gut-targeted therapy — activity tracks with bowel inflammation; treat the gut.

### Note on Classification
Although this topic involves the oral mucosa, the source file grouped aphthous ulcers under cutaneous EIMs (section 3.6). Cross-reference: `oral/` folder — angular cheilitis, OFG, periodontal disease.
