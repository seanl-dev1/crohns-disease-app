# IgA Nephropathy

Reference file for Claude. Technical language. Evidence graded where available.

## EIM: IgA Nephropathy

- Increased prevalence in IBD (shared mucosal immunity hypothesis) [LOW EVIDENCE - population studies with mixed findings].
- Monitor urinalysis periodically; refer nephrology if hematuria/proteinuria.

### Specialist Referral
Nephrology — unexplained proteinuria, hematuria, or creatinine rise.

### Evidence Grade
- IgA nephropathy association with IBD — **[LOW EVIDENCE]**
