# Metabolic Bone Disease — Osteopenia / Osteoporosis

Reference file for Claude. Technical language. Evidence graded where available.

## EIM: Osteoporosis

- **Prevalence**: Osteoporosis **13-42%** in IBD; osteopenia 30-50%.
- CD > UC risk, likely due to terminal ileal disease, malabsorption, higher steroid exposure.
- **Risk factors**: Cumulative corticosteroid exposure (>3 months of prednisone ≥7.5 mg/day), low BMI, postmenopausal, hypogonadism, smoking, vitamin D deficiency, calcium malabsorption, disease duration, bowel resection.
- **Screening (ACG 2017 / CCF guideline)**: DEXA at IBD diagnosis in any patient with risk factors; repeat every **2-3 years** depending on baseline and risk. More frequent if on chronic steroids.
- **Treatment**: Calcium (1000-1200 mg/day), vitamin D (800-2000 IU/day to 25-OH-D >30 ng/mL), weight-bearing exercise, bisphosphonates if T-score ≤-2.5 or prior fragility fracture. Avoid chronic steroids; use budesonide over prednisone when possible.

### When to Worry
- Fragility fracture, height loss, chronic steroid use → DEXA, start bisphosphonate if T≤-2.5.

### Monitoring
- **DEXA scan**: Baseline if risk factors; repeat **every 2-3 years** (more frequently if on ≥3 months steroids).
