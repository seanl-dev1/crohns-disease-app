# Bronchiectasis / Interstitial Lung Disease (ILD)

Reference file for Claude. Technical language. Evidence graded where available.

Pulmonary EIMs are uncommon but underdiagnosed; estimated **<5%** clinically apparent.

## EIM: Bronchiectasis / ILD

### Airway Disease
- Chronic bronchitis, bronchiectasis, tracheobronchitis, subglottic stenosis — reported in IBD.
- Bronchiectasis post-colectomy in UC is a recognized entity [LOW-MODERATE EVIDENCE].

### Parenchymal Disease
- Organizing pneumonia (COP/BOOP), interstitial lung disease, pulmonary granulomas (rare).
