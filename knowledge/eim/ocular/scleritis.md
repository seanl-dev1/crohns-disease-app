# Scleritis

Reference file for Claude. Technical language.

## EIM: Scleritis

- **Less common but more serious**; can threaten vision.
- **Appearance**: Deep, boring ocular pain (worse at night), violaceous hue, tenderness to palpation, photophobia.
- **Urgency**: Same-day ophthalmology referral.
- **Treatment**: Systemic NSAIDs (cautiously, or COX-2), systemic steroids, immunomodulators, anti-TNF.

### Treatment Principle
Uveitis / scleritis typically needs its own or additional therapy.

### When to Worry
- Deep ocular pain worse at night + violaceous sclera → Scleritis. **Same-day ophthalmology**.

### Specialist Referral
Ophthalmology — any red eye with pain/photophobia/vision change — same-day if uveitis or scleritis suspected.
