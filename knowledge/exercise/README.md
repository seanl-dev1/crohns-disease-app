# Knowledge — Exercise and Movement in Crohn's

**Scope:** Reference library for Claude to use when answering questions about exercise physiology, movement, and rehabilitation in Crohn's disease. Covers pathophysiology, evidence for exercise interventions, prescriptive detail, contraindications, and post-operative considerations.

**Split from:** `09-exercise-and-movement.md` (previously monolithic, 882 lines).

**Evidence grading shorthand (used throughout):**
- **[A]** — Multiple RCTs / systematic review of RCTs, consistent findings
- **[B]** — At least one RCT or several well-designed non-randomized studies
- **[C]** — Small uncontrolled studies, case series, or extrapolation from adjacent fields (general IBD or non-IBD populations)
- **[D]** — Expert opinion / mechanistic reasoning only
- **[Weak]** — Marked inline where the evidence base is particularly thin
