# Practical Integration Framework

## META: integration-framework

### Tier 1 — "First-line low-risk high-evidence" (for any CD patient)
1. **Vitamin D** — target 50-60 ng/mL; 2,000-5,000 IU D3/day; K2 + Mg cofactors
2. **Mediterranean diet pattern** — actually better CD evidence than most supplements
3. **Yoga/mindfulness/meditation** — stress is a flare trigger; no downside
4. **Sleep hygiene, regular exercise, smoking cessation** — foundational (not "alternative" per se)
5. **Address iron, B12, folate deficiencies** — especially post-resection

### Tier 2 — "Reasonable adjuncts with moderate evidence"
1. **Curcumin** (Theracurmin 360 mg/day OR 2-3 g standard curcumin + piperine) — **with LFT monitoring every 3-6 months**; stop if liver symptoms
2. **Boswellia serrata** (standardized extract 350-400 mg TID) — good safety
3. **Omega-3 from diet** (fatty fish 2-3x/week) — cardiometabolic, not disease-modifying for CD
4. **Gut-directed hypnotherapy** — if IBS overlap symptoms persistent
5. **Acupuncture** — as time/budget allows

### Tier 3 — "Consider in specific contexts"
1. **EEN / CDED + PEN** — induction alternative to steroids, pre-op optimization, or rescue in flare
2. **Zinc carnosine** (75 mg BID × 8 weeks) — active flare, recent NSAID exposure, barrier rehabilitation
3. **Probiotics (VSL#3/Visbiome)** — if post-resection and concerned about dysbiosis; limited CD evidence
4. **Cannabis/CBD** — if symptom burden (pain, sleep, anxiety, appetite) inadequately controlled; not for disease modification

### Tier 4 — "Experimental/monitor developments"
1. **FMT** — clinical trials only
2. **VNS / ta-VNS** — mechanistically exciting; not ready for routine use
3. **Specific microbial consortia** (SER-287, VE202, etc.) — investigational
4. **Helminth/TSO therapy** — largely abandoned after negative trials

### Tier 5 — "Avoid"
1. Colloidal silver
2. MMS / chlorine dioxide
3. Aloe latex / whole-leaf aloe
4. High-dose oral ferrous salts in active inflammation
5. NSAIDs including willow bark
6. St. John's wort (if on immunosuppression)
7. Unregulated supplements without third-party verification

### For Sean Specifically (20-year post-resection CD, natural health interest)
**Highest priorities given your context:**
1. **Vitamin D optimization** — post-resection = higher malabsorption risk; target 50-60 ng/mL
2. **B12 monitoring and repletion** — ileal resection = lifelong B12 malabsorption risk; sublingual or injection
3. **Bile acid malabsorption screening** — common after resection; cholestyramine/colesevelam if present
4. **Bone density** — DEXA every 2-3 years; adequate calcium, D, K2, weight-bearing exercise
5. **Iron status** — if deficient, IV preferred in active inflammation; oral maltol if mild
6. **Mediterranean diet** — well-supported, sustainable
7. **Stress management stack** — yoga + breathing + GDH if IBS overlay
8. **Curcumin trial** with LFT monitoring if interested (Theracurmin 360 mg/day cleaner data)
9. **Honest assessment of current disease activity** — fecal calprotectin, CRP, periodic endoscopy — so you know if any intervention is actually working
