# Lifestyle Triggers — Per-Topic Knowledge Index

Per-topic reference files split from the original monolithic `12-lifestyle-triggers.md`. Each file is self-contained with YAML frontmatter, a grep-anchored entity-block header (`## LIFESTYLE: <slug>`), and preserved PMIDs/citations.

## Files

| File | Topic | One-line summary |
|---|---|---|
| [smoking.md](smoking.md) | smoking | Single best-established modifiable CD risk factor; cessation improves course within ~12 months (Cosnes 2001, PMID 11266373). |
| [nsaids.md](nsaids.md) | nsaids | Probable flare precipitant via COX/prostaglandin depletion; acetaminophen is first-line; low-dose aspirin acceptable if CV-indicated. |
| [alcohol.md](alcohol.md) | alcohol | Mucosal/microbiome effects at ≥30 g/day; major drug interactions with methotrexate and thiopurines; beer/cider worst for active disease. |
| [dietary-emulsifiers.md](dietary-emulsifiers.md) | dietary-emulsifiers | CMC, P80, carrageenan, TiO₂/E171, sucralose, maltodextrin, nitrites, sulfites, MSG, food colorings — additive hypothesis and evidence. |
| [ultraprocessed-foods.md](ultraprocessed-foods.md) | ultraprocessed-foods | NOVA 4 foods: ~1.7–2.0× CD risk highest-vs-lowest quartile across multiple cohorts (Lo, Narula, Chen). |
| [shift-work-circadian.md](shift-work-circadian.md) | shift-work-circadian | Circadian disruption plausibly worsens CD via microbiota diurnality and systemic inflammation; specific IBD HR not firmly established. |
| [sleep-deprivation.md](sleep-deprivation.md) | sleep-deprivation | Impaired sleep → 2.0× active CD at 6 months (Ananthakrishnan 2013, PMID 23376797); U-shaped <6 h / >9 h risk; screen for OSA. |
| [chronic-stress.md](chronic-stress.md) | chronic-stress | Stress does not cause CD but precipitates flares; CBT, hypnotherapy, mindfulness, and exercise modestly modify disease trajectory. |
| [oral-hygiene.md](oral-hygiene.md) | oral-hygiene | Periodontitis–IBD OR ~2–3; oral Klebsiella and Fusobacterium nucleatum translocate to gut; treat periodontal disease aggressively. |
| [air-pollution.md](air-pollution.md) | air-pollution | Kaplan 2010 Calgary cohort: NO₂ → CD risk in young adults; PM2.5 Mendelian randomization signal; HEPA + AQI-aware exertion. |
| [oral-contraceptives.md](oral-contraceptives.md) | oral-contraceptives | OCPs: RR 1.51 for CD (Cornish 2008, PMID 18684177); modest effect; reverts after discontinuation; HRT and menstrual cycle covered. |
| [infections-vaccinations.md](infections-vaccinations.md) | infections-vaccinations | Salmonella/Campylobacter → HR 2.9 for IBD (Gradel 2009, PMID 19361507); vaccine safety framework — live contraindicated on biologics. |
| [obesity-adiposity.md](obesity-adiposity.md) | obesity-adiposity | BMI ≥30 → CD risk; visceral fat > BMI as prognostic marker (Gu 2023, PMID 37307420); creeping fat is pathognomonic and bacteria-laden. |
| [antibiotic-exposure.md](antibiotic-exposure.md) | antibiotic-exposure | Childhood antibiotics → new-onset CD OR 1.74 (Ungaro 2014, PMID 25223575); dose-response; adult cumulative exposure also implicated. |
| [occupational-exposures.md](occupational-exposures.md) | occupational-exposures | Weak hypothesis-generating signals for welding, solvents, farming (mixed), hair dressing, printing. Not actionable beyond standard PPE. |
| [geographic-migration.md](geographic-migration.md) | geographic-migration | Westernization gradient; Canadian migrant cohort (Benchimol 2015, PMID 25756238): environment trumps genetics at population level. |
| [cold-weather-vitamin-d.md](cold-weather-vitamin-d.md) | cold-weather-vitamin-d | Winter/seasonal flare signal plausibly mediated by 25-OH-D; bidirectional relationship; target >30 ng/mL, some specialists >40 ng/mL. |
