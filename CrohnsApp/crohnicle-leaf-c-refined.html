Finalist · Refined

Leaf-C

A single leaf whose silhouette is already a C. Timeless, warm, and unmistakably about living well.

Step One

From sketch to master

The first-pass mark worked conceptually but the path had redundant curves and uneven weight. The refined version rebuilds the silhouette with four clean Bézier segments.

Original sketch
Asymmetric weight, lumpy inner curve, tip slightly blunt.
Refined master
Balanced silhouette, sharper tip, elegant inner C-curve.
  • Sharpened tipControl point moved closer to anchor so the tip reads pointed, not rounded.
  • Balanced outer curveTwo symmetric segments replace the original single curve — more elegant at any size.
  • Cleaner C negative spaceInner concave reconstructed with a single flowing bend, creating a visible "C" on the right edge.
